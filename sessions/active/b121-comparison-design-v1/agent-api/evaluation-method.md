用户最新确认取代此前“直到成功测试完”的停止目标：**取得预先约定条件下的完整结果即结束，失败也构成结果**。既有授权不构成“失败后不断调参直到通过”的要求。既有费用上限继续有效；未知费用预留不能凭期待释放。

保留两个不同问题：
- judgment-only：给定等价事实，Graph/plain 是否帮助正确判断后果与证据边界；不把这个分数叫 API 易用性。
- Graph entry：在固定的材料、工具与资源条件下，参与者能否发现并正确使用接口。当前材料是受限源码包，不是成熟文档入口；结论只能覆盖这个条件，不能外推到所有用户、语言或模型。

## 一次正式轮的冻结清单

开始前保留一份完整、带摘要绑定的 manifest，逐项填实，不能用“待定”值启动正式轮：

| 必须固定的内容 | 核对方式 |
|---|---|
| 测量问题、任务、预期产物、角色、样本数、G/P 信息等价性 | 任务与分配表；entry 不虚构 P 对照 |
| library 修订、源码／文档包、可访问路径、初始可见信息 | 内容摘要；记录源码或文档支持条件 |
| 全部提示、工具 schema／行为、会话隔离、历史保留方式 | harness 与材料摘要；不得临时总结接口、指出正确文件或补答案 |
| 模型、路由、采样／推理设置、alias 限制 | 请求配置与路由证据；更换 provider 另记环境版本 |
| 每次上下文、累计输入／输出、操作数、时间、总费用、未知费用预留与重试规则 | 各限制独立列出；预设资源不足时如何记录未运行项 |
| 评分标准、编译配置、语义审查、分母、缺失处理、终止条件 | rubric 与评分器摘要；不按观察到的答案改标准 |
| 开发集与未用于调试的保留任务 | 披露谁见过任务／答案及用途；不能将本次已反复调试的题改名叫新题 |

正式轮允许逐个调度任务，失败无需重跑整套，但样本与顺序必须提前登记。每个预定样本都有唯一记录；未运行项明确标记。正式过程中只观察、记录和按冻结规则处理重试，不根据结果改变提示、工具、预算、题目或成功条件。出现 harness 缺陷需修复时，结束并保存当前轮为受影响／无效轮，修复后另开评测版本；不得覆盖失败。

## 同等保留，分别归因

所有预定样本都进入结果总表。分别报告“完成／未完成／未运行”“提交是否合格”“评分是否有效”和“失败原因及证据”。不能把预算停止当作答错，也不能把它从样本数里删掉来提高通过率。可给出已完成样本上的条件分数，但必须同时报告全体样本的完成率与覆盖，不能替代全体结果。

| 观察 | 保留的结果 | 可支持的解释与限制 |
|---|---|---|
| 无效答案值、调用格式错误 | 对应样本失败与原始调用 | 模型／接口交互失败；不足以单独认定模型或 library 的根因 |
| 搜索不断扩展、累计预算停止 | 未完成；实际用量、搜索轨迹、停止点 | 给定条件下未完成；可能是可发现性、材料、模型策略或预算问题 |
| HTTP／网络失败或费用保护停止 | 中断及未运行项 | 执行／观测受限；不推出 library 功能错误 |
| harness 拒绝本应支持的操作 | 原始失败、缺陷证据、受影响样本 | 评测器缺陷；修复不能将原样本追认为成功 |
| 有代码但编译／语义检查失败 | 原始提交、诊断、逐项评分 | 区分接口使用错误与真正实现缺陷；不替模型修答案 |

原因允许多标签或“尚不明确”。相同保留规则不意味着所有原因具有相同归责。只凭预算耗尽或三种角色都失败，不能归因整个 library。

## 迭代与对比

1. 先完成开发集上的执行可行性检查和文档入口审计；开发结果不用于正式排名。
2. 冻结正式问题、材料条件、任务与上述配置。源码支持与文档支持若都要测，分别登记；不能运行中互相补充。
3. 正式轮按预定样本执行一次，冻结规则允许的基础设施重试单独记录。有效失败结束该样本，不以获得成功样本为目标追加尝试。
4. 复盘形成“证据 → 假设 → library 改进 → 可验证效果”，按所属 package 的既有设计／实现流程修改；不把修改实验题目等同于改进 library。
5. library 新版本先跑旧题作为已暴露的回归集，再在独立保留题上检验泛化。旧题提升可能来自针对性优化，不能单独证明普遍易用性；新旧 library 可在同一套新保留题、同一 harness／模型配置下做配对比较。
6. harness、模型或材料政策若同时变化，分别记录版本；无法控制时披露混杂，不把总提升全部归给 library。

目前只落实方法、保全试运行证据与整理改进假设。新的正式任务集、完整冻结清单和可用支出额度尚未就绪；api-campaign.mjs 已新增单任务开发选择（见[离线工具验证](single-task-preparation.md)），但尚未实现正式任务分配与机器强制上述全部方法约束。
