## 推荐的测量问题

在提供真实使用者可接触的**现有文档＋源码**、固定工具和资源后，模型能否独立找到并正确使用目标接口？参与者得到示例目录的README入口，不得到由Codex针对题目挑选的正确源码行、调用顺序或实现摘要。

## 材料政策（待实现与离线验证）

- 对所有待比较library版本用相同的选择规则：从相同示例目录文档入口开始，包含其正式使用文档、示例及所需本地源码依赖。列出实际文件清单、字节／行数和未满足的链接／import，不能把“闭包”当作已验证的事实。

- 工具仅对冻结包list/search/read；正常未命中可纠正，工具操作与错误均计量。参与者不能访问实时仓库、控制器或外部网络。
- 检索／写代码阶段只通过事件分类观察，默认保留模型自己的上下文。不要让Codex在阶段之间替它筛选／总结证据；若将来测试有辅助的分阶段方案，另设条件。
