## 材料边界和已知缺口

结构检查记录385处included引用、3处restricted、8处external（计出现次数，不是独立文件数）。缺失的设计文档、fixture harness和oracle保持未收录：

- demo引用fixture harness/oracle；demo源码保留为原有使用文档，示例中的断言也公开保留，但测试夹具与oracle文件本身不进入材料。
