Why the graph exists

Three ordinary docs problems become topology problems.

01

Hidden coordination.

When updates are spread across callbacks, logs, queues, and hand-written glue, the structure is hard to inspect and harder to explain.

GraphReFly

Declared topology.

Inputs, reductions, and effects are named graph nodes with explicit edges. The shape is readable before a single value moves.

02

Stale joins.

Fan-out and fan-in are easy to describe and surprisingly easy to get wrong when each branch reports at a different time.

GraphReFly

Wave semantics.

DIRTY marks the reachable graph before DATA settles. A joining node sees the changed inputs together, then computes once.

03

Package drift.

Shared concepts rot when every language page tries to copy API details from every other implementation.

GraphReFly

Curated shell, delegated APIs.

This site teaches the shared model and routes to package-owned TypeScript, Python, and Rust references for exact syntax.

Requirement panel

A public docs layer has to stay useful without becoming the control surface.

The shared site borrows the old homepage's visual rhythm, but the copy now follows the public-docs boundary: teach the model, route to packages, and keep implementation governance out of the developer path.
