Wave-based propagation

After activation, updates move in two phases.

START belongs to subscription. Once edges exist, an update wave dirties the reachable downstream cone first, then lets values settle through the graph.

1DIRTY floodReachable downstream edges are marked before values move.
2DATA phaseValues travel only after the dirty phase closes.
3Join settleThe diamond recomputes once from settled inputs.
4Terminal downCOMPLETE is down-only; sealed nodes send no later DATA.
