Reactive Graph Protocol · Causal Tracing

Graph+Re[active]=Fly

GraphReFly is a reactive graph protocol for declared, inspectable reduction. Humans, tools, and AI systems can compose work as topology: changes propagate through explicit edges, outputs update only when their inputs demand it, and every flow stays observable.
